## 📌 Executive Summary

For **Task 11**, I designed and deployed an enterprise-grade, highly available IT Asset Management (ITAM) portal using **Snipe-IT** and **MariaDB 11.4** on **AWS EC2**. The infrastructure was provisioned using **Terraform (Infrastructure as Code)**, containerized via **Docker Compose (v2)**, and completely populated with foundational organizational entities, 9 high-spec hardware assets with latest market pricing and product photos, custom fieldsets, and consumables via the Snipe-IT REST API.

## 🏗️ Technical Architecture & Implementation

```
                          ┌──────────────────────────────────────┐
                          │            AWS Cloud VPC             │
                          │                                      │
  Internet / Browser ────►│ Inbound Security Group               │
  (Port 8000 / Port 22)   │ - TCP 22   (SSH Management)          │
                          │ - TCP 8000 (Snipe-IT Web UI)         │
                          │ - TCP 80/443 (HTTP/HTTPS)            │
                          └──────────────────┬───────────────────┘
                                             │
                                             ▼
                      ┌──────────────────────────────────────────────┐
                      │    AWS EC2 Instance (Ubuntu 24.04 LTS)       │
                      │    (t3.micro + 2GB Swapfile OOM Guard)       │
                      │                                              │
                      │  ┌──────────────────┐  ┌──────────────────┐  │
                      │  │ Snipe-IT App     │  │ MariaDB 11.4     │  │
                      │  │ Container        │  │ Container        │  │
                      │  │ (snipe/snipe-it) │◄─┤ (mariadb:latest) │  │
                      │  │ Port 8000 -> 80  │  │ Port 3306 (int)  │  │
                      │  └────────┬─────────┘  └────────┬─────────┘  │
                      │           │                     │            │
                      │           ▼                     ▼            │
                      │     Docker Volume         Docker Volume      │
                      │       `storage`             `db_data`        │
                      └──────────────────────────────────────────────┘
```

### 1. Cloud Infrastructure (Terraform)
- **Compute:** AWS EC2 `t3.micro` running **Ubuntu Server 24.04 LTS** in `ap-south-1` (Mumbai).
- **Storage:** 20 GB `gp3` root EBS volume.
- **Security Group:** Inbound rules strictly restricted to Port 22 (SSH), Port 8000 (Snipe-IT Web UI), Port 80 (HTTP), and Port 443 (HTTPS).
- **Security Credentials:** RSA 4096-bit key pair automatically generated by Terraform.

### 2. High Availability & Memory Safety
- Configured a dedicated **2 GB persistent swapfile** (`/swapfile`) with `vm.swappiness=10`. This mitigates MariaDB Out-Of-Memory (OOM) killer crashes on 1 GB RAM instances during schema migrations.

### 3. Container Orchestration & Docker Compose
- Deployed official `snipe/snipe-it:latest` web container and `mariadb:11.4` database container.
- Maintained Docker healthcheck dependencies ensuring `app` only starts when `db` is fully `healthy`.
- Data persistence guaranteed using named Docker volumes: `db_data` for MariaDB data and `storage` for uploads and encrypted keys.
